## 📦 Problem Solved
Default WooCommerce checkout requires customers to type free-text city and state names. In Bangladesh, courier services (Steadfast, Pathao, RedX, Paperfly) strictly require standardized 64 districts and 500+ thanas/upazilas. Typing typos lead to parcel misrouting and high return-to-origin (RTO) costs.

This package provides a zero-AJAX, pre-compiled JSON cascading dropdown integration for standard WooCommerce and CartFlows funnels, fully compatible across PHP 7.4 through PHP 8.5.
